### Deterministic build

Both documents build with the same four-step sequence. Setting `SOURCE_DATE_EPOCH` (and
`FORCE_SOURCE_DATE`) pins the timestamps pdfTeX embeds, which is what makes repeated builds
byte-identical; without it two builds differ only in `/CreationDate`, `/ModDate` and the file `/ID`.

```
export SOURCE_DATE_EPOCH=1755000000 FORCE_SOURCE_DATE=1
pdflatex -interaction=nonstopmode main
bibtex   main
pdflatex -interaction=nonstopmode main
pdflatex -interaction=nonstopmode main        # -> main.pdf

pdflatex -interaction=nonstopmode supplement
pdflatex -interaction=nonstopmode supplement  # -> supplement.pdf  (no bibliography)
```
